# DESIGN.md — 현생 RPG 디자인 시스템

PRD 8장 기반. 이 파일이 디자인의 단일 진실 공급원(SSOT)입니다.

---

## 테마

- **다크모드 전용** — 라이트모드 없음, 절대 추가하지 않음
- **무드:** 게임 터미널, 레트로 RPG, 픽셀 감성

---

## 레이아웃

- **최대 너비:** 430px (모바일 우선, 앱처럼 보이도록)
- **중앙 정렬:** `mx-auto`
- **하단 탭 네비게이션:** 고정 위치 (`fixed bottom-0`)
- **페이지 패딩:** 좌우 `px-4`, 상하 `pt-4 pb-24` (탭바 공간 확보)
- **카드 패딩:** `p-4`
- **카드 보더레이디우스:** `rounded-lg` (8px)
- **카드 간격:** `gap-3`

## 컴포넌트 패턴

### 카드

```jsx
<div className="bg-[#12121a] border border-[#2a2a3a] rounded-lg p-4">
  ...
</div>
```

### 프로그레스 바 (능력치)

- 8칸 블록 형태 (픽셀 감성)
- 각 블록: `w-4 h-3 rounded-sm`
- 채워진 블록: 능력치 수치에 따라 상태 컬러 적용
  - 70 이상 → `#5dcaa5` (긍정)
  - 40~69 → `#ef9f27` (경고)
  - 39 이하 → `#f0997b` (위험)
- 빈 블록: `bg-[#1e1e2e]`

### 태그 / 뱃지 (Pill)

```jsx
<span className="text-xs px-2 py-0.5 rounded-full bg-[#1e1e2e] text-[#afa9ec] border border-[#2a2a3a]">
  월요병
</span>
```

### 버튼 — 메인

```jsx
<button className="w-full bg-[#534ab7] hover:bg-[#4340a0] text-white font-mono text-sm py-3 rounded-lg transition-colors">
  오늘의 패치노트 작성
</button>
```

### 버튼 — 서브 (탭 버튼)

```jsx
// 선택됨
<button className="px-3 py-1.5 rounded bg-[#534ab7] text-white text-xs font-mono">
  2끼
</button>
// 선택 안됨
<button className="px-3 py-1.5 rounded bg-[#1e1e2e] text-[#6b7280] text-xs font-mono hover:text-white">
  2끼
</button>
```

### 슬라이더 (수면 시간)

- 기본 `input[type=range]` 커스텀 스타일
- 트랙: `#1e1e2e`, 채워진 부분: `#534ab7`

### 카운터 (+/−)

```jsx
<div className="flex items-center gap-3">
  <button className="w-8 h-8 bg-[#1e1e2e] text-white rounded">−</button>
  <span className="text-white w-6 text-center font-mono">2</span>
  <button className="w-8 h-8 bg-[#1e1e2e] text-white rounded">+</button>
</div>
```

### 이모지 선택기

- 8종 격자 배열 (4×2)
- 선택된 이모지: `ring-2 ring-[#534ab7]` + `bg-[#1e1e2e]`

## 네비게이션 (하단 탭바)

4개 탭: 캐릭터 시트 / 패치노트 / 캘린더 / 분석

```
[캐릭터] [패치노트] [캘린더] [분석]
```

- 배경: `#12121a`, 상단 테두리: `border-t border-[#2a2a3a]`
- 활성 탭 아이콘/레이블: `#afa9ec`
- 비활성 탭: `#6b7280`
